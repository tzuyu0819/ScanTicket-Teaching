📘 公出交通費自動填表術操作教學 CookBook

步驟一. 將車資轉成 CSV ＋
  1. 在網址列輸入：http://172.17.1.56:5500/index.html
  2. 點選「附件上傳」，選擇掃描的 PDF
  3. 等待程式分析
  4. 確認無誤後，點「匯出 CSV」
步驟二. 下載 & 執行 自動填寫程式 ＋
  1. 下載 自動登打車資.exe
  2. 執行程式並登入 BPM
  3. Chrome 自動登入
  4. 開啟步驟二第4點下載的 CSV
  5. 程式自動填寫（注意事項見提醒）
步驟三. 疑難雜症排除 ＋
1. MAC 電腦可以執行程式嗎？ ＋
不行，Mac 無法直接執行 Windows 的 .exe，需要安裝 Windows 虛擬機。
2. 掃描的票據可以一張 A4 貼不同日期嗎？ ＋
不建議。一張 A4 只貼一個日期，再掃描。
3. 附件上傳支援哪些格式？ ＋
支援 PDF 與各種清晰圖檔，並包含日期、交通工具、費用等資訊。
4. 若 AI 分析結果錯誤怎麼辦？ ＋
先檢查票據清晰度；仍錯誤可在網頁上修改後再匯出 CSV。
5. 上傳後還能新增資料嗎？ ＋
可以，點「新增一筆」手動輸入後再匯出 CSV。
6. Chrome 顯示密碼外洩警告怎麼辦？ ＋
這是 Chrome 密碼檢測提醒，建議更新密碼後再使用程式。
